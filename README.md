# Dioxus Skill

Expert Dioxus development toolkit for [pi](https://pi.dev/) coding agents.

Covers Rust-based cross-platform app development for web, desktop, mobile, and server — including `dx` CLI workflows, RSX components, signals state management, fullstack server functions, and iOS/Android builds.

## Install

```bash
pi install git:github.com/vl4dt/dioxus-skill
```

## Structure

```
dioxus-skill/
├── SKILL.md          # Main instructions (quick reference)
├── REFERENCE.md      # Detailed docs (FFI, bundle config, CI/CD)
└── .gitignore        # Build artifacts
```

## Contents

- DX CLI commands reference
- Core patterns: components, signals, hooks, props, async, server functions
- Mobile builds (Android + iOS)
- Remote Mac build setups
- Cross-platform feature matrix
- Debugging and troubleshooting
